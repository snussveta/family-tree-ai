# FamilyMind AI — Интерактивная нейрокарта семьи и окружения

Интерактивное веб-приложение: майнд-карта семьи и близких в стиле светящегося графа связей нейросети с встроенным персональным AI-консьержем на базе Google Gemini API (с поддержкой Function Calling / Tool Use).

---

## 🌟 Возможности приложения

1. **Интерактивный 2D Force-Directed Граф:**
   - Темно-синяя неоновая эстетика с визуализацией узлов и плавных связей.
   - **Лиза** — главный центральный узел (выделена розово-пурпурным свечением, короной и увеличенным размером).
   - Светящиеся частицы, летящие по линиям связей.
   - Цветовая дифференциация по ролям (родители, брат/сестра, бабушка/дедушка, друзья).
   - Перетаскивание узлов, масштабирование колесиком мыши, центрирование и фит графа.
   - Поиск по имени и увлечениям с подсветкой подходящих узлов.

2. **Карточка деталей человека:**
   - Клик по любому узлу открывает стильную выдвижную панель с деталями.
   - Дата рождения, текущий возраст и счетчик дней до следующего дня рождения.
   - Бейджи хобби и увлечений.
   - Предпочтения, вкусы, размеры одежды и антипатии.
   - Заметки и интерактивный список связей с другими родственниками.
   - Кнопка прямого запроса к ИИ: *"Спросить ИИ об идеях подарка"*.
   - Редактирование и удаление данных.

3. **AI-Консьерж (Google Gemini с Function Calling):**
   - Выдвижной мессенджер с поддержкой Markdown.
   - Знает всю структуру графа, хобби, предпочтения и даты рождения.
   - **Автодополнение данных (Function Calling):**
     - `update_person_info`: если вы пишете *"брат пошел на курсы дайвинга и любит зеленый чай"*, ИИ автоматически вызывает инструмент и обновляет запись в SQLite!
     - `add_relative`: если вы говорите *"добавь дядю Олега, он охотник"*, ИИ создает нового человека и связывает его с графом.
   - **Проактивность:** если у человека не заполнена дата рождения или хобби, ИИ может ненавязчиво поинтересоваться ими в конце ответа.
   - Быстрые подсказки-чипсы:
     - 🌸 *"Какие цветы подарить маме?"*
     - 🎸 *"Что подарить брату до 3000₽?"*
     - 🎂 *"Кто празднует ДР в ближайший месяц?"*
     - 🎁 *"Идеи романтического сюрприза для Лизы"*

4. **Управление картой:**
   - Создание новых людей через модальное окно.
   - Соединение людей произвольными связями (*"мама"*, *"папа"*, *"друг"*, *"коллега"*).
   - Кнопка мгновенного сброса к исходным демо-данным (Лиза, мама, папа, брат, бабушка, друг, сестра).
   - Настройка ключа Gemini API и модели прямо в интерфейсе через диалог настроек.

---

## 🛠 Стек технологий

- **Frontend:** Next.js 16 (App Router, React 19, TypeScript), Tailwind CSS, Lucide Icons, React Markdown.
- **Визуализация:** HTML5 Canvas Force-Directed Network Engine (`force-graph`).
- **Backend / API:** Next.js Route Handlers.
- **База данных:** SQLite через Prisma ORM.
- **AI Engine:** Google Gemini API (`@google/generative-ai` / `@google/genai`, модели `gemini-2.0-flash`, `gemini-1.5-flash`) с Function Calling (Tool Use).
- **Контейнеризация:** Docker & Docker Compose (мультистейдж-сборка, автоматический сидинг).

## 🚀 Быстрый старт локально

### 1. Клонирование и установка зависимостей
```bash
git clone <url-вашего-репозитория>
cd tree
npm install
```

### 2. Настройка переменных окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Откройте `.env` и при необходимости укажите ваш ключ Gemini API:
```env
DATABASE_URL="file:./dev.db"
GEMINI_API_KEY="AIzaSy..."
GEMINI_MODEL="gemini-2.0-flash"
```
*(Бесплатный ключ можно получить за 1 минуту в [Google AI Studio](https://aistudio.google.com/app/apikey). Если ключ не указан в `.env`, его можно ввести прямо в интерфейсе приложения через значок ⚙️).*

### 3. Инициализация базы данных и сидинг демо-данных
```bash
npx prisma db push
npm run seed
```

### 4. Запуск сервера разработки
```bash
npm run dev
```
Откройте браузер по адресу: **http://localhost:3000**

## ☁️ Деплой на чистый сервер Oracle Cloud (Ubuntu) в 1 команду

Oracle Cloud предоставляет мощные бесплатные виртуальные серверы (Always Free, до 4 ядер ARM Ampere / 24 GB RAM или AMD).

### Шаг 1. Подключение к серверу
Подключитесь по SSH к вашей виртуальной машине Ubuntu:
```bash
ssh ubuntu@<IP_ВАШЕГО_СЕРВЕРА>
```

### Шаг 2. Установка Docker и Docker Compose (если еще не установлены)
Выполните стандартную установку Docker в Ubuntu:
```bash
sudo apt update && sudo apt upgrade -y
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER
newgrp docker
```

### Шаг 3. Открытие порта 3000 в файрволе Ubuntu
На виртуальных машинах Oracle Cloud Ubuntu по умолчанию включен `iptables`/`ufw`:
```bash
# Разрешить входящий трафик на порт 3000
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 3000 -j ACCEPT
sudo netfilter-persistent save
```
> **Важно в консоли Oracle Cloud:** В настройках вашей VCN (Virtual Cloud Network) -> Security Lists добавьте Ingress Rule:
> - **Source CIDR:** `0.0.0.0/0`
> - **IP Protocol:** `TCP`
> - **Destination Port Range:** `3000`

### Шаг 4. Клонирование и запуск в 1 команду
```bash
git clone <url-вашего-репозитория>
cd tree

# Создайте .env и укажите ваш ключ
cp .env.example .env
nano .env # (вставьте GEMINI_API_KEY="...")

# Запуск контейнера в фоновом режиме
docker compose up -d --build
```

Контейнер автоматически:
1. Соберет оптимизированный образ Next.js.
2. Примонтирует том `./data` для постоянного хранения SQLite базы данных.
3. Проверит состояние базы данных и автоматически наполнит её демо-сетью Лизы и родственников.
4. Запустит сервис на порту `3000`.

### Шаг 5. Проверка работы
Откройте в браузере:
```text
http://<IP_ВАШЕГО_СЕРВЕРА_ORACLE>:3000
```

Для просмотра логов:
```bash
docker compose logs -f
```

Для остановки:
```bash
docker compose down
```
